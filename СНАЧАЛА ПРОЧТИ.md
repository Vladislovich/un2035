# Наземная станция БПЛА — быстрый старт

Дрон (Orange Pi с кодом Иры) находит людей, дым и ArUco-маркеры и шлёт на ноутбук
находки, телеметрию и живое видео. Ноутбук считает координаты объектов (формула Миши)
и показывает всё в браузере: видео с рамками, кадры находок, координаты, карту.

**На плате уже всё установлено и собрано — её трогать не нужно.**
На ноутбук нужен только Python 3.

## Что в архиве

| | |
|---|---|
| `Запустить станцию.bat` | запуск станции двойным кликом |
| `Проверка без дрона.bat` | станция + имитатор дрона, чтобы посмотреть интерфейс без железа |
| `ИНСТРУКЦИЯ.md` | **полная инструкция**: настройки, нюансы, что делать, если не работает |
| `Демо (40 с).mp4` | как это выглядит вживую |
| `station/` | программа станции и веб-интерфейс |
| `onboard/` | исходники бортовой программы со всеми правками (для справки и пересборки; на плате уже собрано) |

## 1. Один раз на новом ноутбуке

1. **Python 3.8 или новее** с [python.org](https://www.python.org/downloads/).
   При установке **поставить галочку «Add Python to PATH»**. Больше ничего ставить не нужно
   (для `Проверка без дрона.bat` OpenCV поставится сам).
2. Распаковать архив в любую папку.
3. Подключить ноутбук к **той же Wi‑Fi сети, что и дрон** (сейчас дрон в сети
   `medoed_lab_Wi-Fi5`, его адрес `192.168.3.50`).
4. При первом запуске станции Windows спросит про доступ Python к сети —
   **разрешить** (частные сети). Иначе дрон не сможет подключиться.
5. Если на ноутбуке включён VPN — исключить из него локальную сеть `192.168.3.0/24`
   (раздельное туннелирование) или выключить VPN. Иначе дрон «не виден».

## 2. Запуск

**Ноутбук:** двойной клик по `Запустить станцию.bat`. Откроется браузер с интерфейсом,
а в окне станции будут напечатаны адреса ноутбука, например:
```
http://192.168.3.209:8080
```
Запомнить этот IP (`192.168.3.209` в примере) — он нужен дрону.

**Дрон** (с ноутбука, в PowerShell или командной строке; пароль платы — спросить у команды):
```
ssh orangepi@192.168.3.50
cd ~/sar_yolo_pipeline
SAR_GROUND_IP=192.168.3.209 ./run.sh test
```
- вместо `192.168.3.209` — **IP вашего ноутбука** из окна станции;
- `test` — проверка на столе: координаты подставные (башня Политеха, 30 м);
- без `test` — боевой режим, координаты с GPS полётника;
- остановить — `Ctrl+C`.

Через несколько секунд в интерфейсе: «Дрон на связи», живое видео, позиция дрона.
Человек или ArUco-маркер в кадре — появится находка в журнале и метка на карте.
Клик по находке — её кадр с рамкой и координатами, «К живому видео» — назад.

## 3. Важное

- **Маркеры ArUco** — словарь **4×4** (номера 0–49), с **белыми полями вокруг**
  чёрной рамки. Без белых полей и маркеры 6×6 не распознаются.
- **Кабель камеры** держится плохо: если дрон тряхнуть, камера переподключается,
  и бортовая программа зависает (видео встаёт). Перезапустить программу на плате;
  если пишет «Не удалось открыть камеру» — см. ИНСТРУКЦИЯ.md, раздел 6.
- **Начать с нуля в новом месте** (чтобы старые находки не мелькали): остановить станцию и
  переименовать папку `station/finds_web`, или запускать с новой папкой:
  `Запустить станцию.bat --dir finds_новое_место`. Подробно — ИНСТРУКЦИЯ.md, раздел 3.4.
- **Порт 5700 слушает только одна программа**: не запускать станцию дважды
  и одновременно с `ground_server.py` / `viewer.py`.
- Режим `test` и надпись «ТЕСТОВАЯ ПОЗА» — координаты условные, в полёт так нельзя.
- Перед настоящим полётом проверить угол обзора и наклон камеры в
  `onboard/src/main.cpp` (`CAMERA_HFOV_DEG`, `CAMERA_TILT_DEG`) — ИНСТРУКЦИЯ.md, раздел 5.

## 4. Вход на плату без пароля (по желанию)

В PowerShell на своём ноутбуке:
```
ssh-keygen -t ed25519
type $env:USERPROFILE\.ssh\id_ed25519.pub | ssh orangepi@192.168.3.50 "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys"
```
Первая — Enter на все вопросы; вторая один раз спросит пароль платы.
Команды выполнять **на ноутбуке**, а не внутри ssh-сессии на плате.

Всё остальное — в `ИНСТРУКЦИЯ.md`.
